# brioche-courses

Versioned French curriculum for Brioche

法语课程源与发布记录已从原仓库的已提交文件抽取，保留原目录路径以保持素材引用有效。课源含私有判分规则，但不含账号数据库或私有配音包。正式音频在生产登记媒体存储中，未复制到 Git。旧课源和发布版本保持不可变。

来源可追溯的原始抽取保持不变。Brioche 现在通过固定 `curriculum` 子模块引用本仓库，产品课源副本已移除；作者命令改为 `curriculum/docs/...`。独立 CI 使用固定 Chef 检查当前48课正式目录的精确 revision、结构、归属与判分。实际生产仍读取已有数据库/媒体登记，不因源目录迁移重新导入或覆盖历史。

拆分设计和验收范围见 [架构说明](docs/architecture.md)。秘密、生产账号、私有声音档案与恢复密钥不得提交。
